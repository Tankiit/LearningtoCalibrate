# P2 / ICLR workspace boundary

`p2_iclr/iclr_2027.md` is the only P2 ledger. P2 preregistrations live under
`p2_iclr/prereg/`. Shared extraction code remains at the repository root until
it is moved into an explicitly paper-neutral `shared/` package.

P1/AISTATS has a separate placeholder ledger at
`p1_aistats/aistats_2027.md`; no P1 results are stored in this P2 workspace.

The P2 cache and figure directories remain at their existing paths during this
transition so analysis scripts and provenance links continue to resolve. They
are P2-owned unless explicitly marked shared.
