# Anonymous Reproducibility Repo: OVA Deferral

This document describes the **fast-path** reproduction route from cached
CSVs. The full training and extraction pipeline (steps 1–6, configs,
data adapters, probes, gap, eval, utils, tests) ships alongside this
file — see `README.md` and `scripts/step1_extract.py` …
`scripts/step6_credal_sets.py` to retrain end-to-end.

The central score is

```text
gap(x) = f_pred(x) - f_defer(x)
```

where `f_pred` predicts model correctness and `f_defer` predicts the
dataset-specific expert-reliability / ambiguity target.

## Contents

```text
data/
  aurc_results.csv                    # selective-prediction AURC matrix
  defer_head_diagnostics_summary.csv  # f_defer target diagnostics
  independence_summary.csv            # geometric/STC/output-correlation diagnostics
  diagnostic_probe_cells.csv          # 18-cell plotting table
  stc_null_calibration*.csv           # STC shuffle/aligned controls
  stc_vs_alpha.csv                    # controlled STC alignment curve
  path2_width_summary.csv             # BDD width and AURC summaries
scripts/
  reproduce.py                        # regenerate figures from data/*.csv
figures/                              # generated by reproduce.py
```

## Reproduce (fast path, CSVs only)

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/reproduce.py
```

The script writes figures into `figures/`. No cloud services, Modal
apps, GPU extraction jobs, or raw hidden states are required.
