# Verbalized conformal confidence

External evidence and source methods copied from
[`ivanvmoreno/correctness-model-internals`](https://github.com/ivanvmoreno/correctness-model-internals)
at commit `aa7270c3c1089393eec8d8179d1581f3ec0c7b80`.

## Contents

- `verbalized_confidence/`: the upstream question-only confidence prompts and published plots.
- `evaluations_revisited/`: original and revisited TriviaQA evaluation CSVs for Llama 3.1 8B,
  Llama 3.3 70B, and Mistral 7B.
- `activation_cache/activations_batch_0_0.pt`: one upstream activation cache from
  `truth_analysis_arnau/activations/activations_cities_right/layer_12/`. It is a CPU-loadable
  PyTorch `float32` tensor with shape `[20, 4096]` (321 KiB). SHA-256:
  `8fe81cb9f10cb39d66085843200715e87dfe4c7e46b99892f9d3109bfd843817`.
- `source_methods/`: the upstream difference-of-centroids implementation and the four notebooks
  used for direction cosine/agreement and cluster-variance analysis.
- `cached_results/`: reproducible outputs for the four local, no-GPU checks, generated by
  `scripts/cached_claim_checks.py`.

## Scope note

The activation cache is an upstream question-position cache and is useful for validating data
loading and reproducing their direction calculation. It is not a paired pre-answer/post-answer
cache, so it cannot by itself estimate `cos(d_q, d_a)`.

The upstream `verbalized_confidence/` directory contains no raw generation files at this commit;
only its parameter file and plots are tracked. The copied `evaluations_revisited/` CSVs contain
answer-generation evaluations, not the verbalized-confidence generations needed for an external
first-digit simulation.
